# 演練素材庫

10 組郵件範本與對應的落地頁，供社交工程演練使用。全部為繁體中文，可直接匯入 phish_wu 或原版 gophish。

## 設計原則

**不冒用任何真實品牌。** 所有情境都建立在「內部部門」與「通用服務」之上——IT 服務台、人力資源部、採購系統、收發中心。這麼做有兩個理由：一是內部來源的郵件在演練中本來就更有效，二是這套素材不會變成可以直接拿去打特定品牌用戶的現成工具。

**預設不儲存密碼。** 所有落地頁的 `capture_credentials` 為 `true`、`capture_passwords` 為 **`false`**。演練要知道的是「誰提交了」，不是「密碼是什麼」。把全公司的真實密碼收進 gophish 資料庫，等於自己建了一個高價值的攻擊目標，而這對教育訓練沒有任何額外幫助。

若你的演練方案確實需要驗證密碼強度，請自行將 `manifest.json` 中該欄位改為 `true`，並確保資料庫加密與保存期限的處理方式已通過內部核可。

**10 個情境全部可觸發三個動作。** 每封信都帶追蹤像素、連結與附件，且信件內文都會提及附件——沒來由的附件本身就是破綻。

### 關於三動作追蹤

本專案將**開啟郵件、開啟附件、點擊連結**記錄為三個互不干涉的獨立事實。素材庫對應如下：

- **開啟郵件** — 每封郵件結尾都有 `{{.Tracker}}`（追蹤像素）
- **點擊連結** — 每封郵件的按鈕都指向 `{{.URL}}`
- **開啟附件** — 10 個 HTML 附件內嵌 `{{.AttachmentTrackingURL}}`

**`.ics` 無法做開啟追蹤。** 行事曆程式不會抓取檔案內的遠端資源。情境 07 因此同時夾帶行事曆邀請與一份 HTML 議程——前者負責讓邀請看起來出自真正的會議系統，後者負責追蹤。

## 匯入

API 金鑰在管理介面的 Settings 頁面。

```bash
cd library
PHISH_WU_API_KEY=你的金鑰 python3 import.py --url https://admin.example.com
```

若管理介面跑在 loopback 上的自簽憑證：

```bash
PHISH_WU_API_KEY=你的金鑰 python3 import.py --url https://127.0.0.1:3333 --insecure
```

先看看會送出什麼，不實際匯入：

```bash
python3 import.py --dry-run
```

只匯入特定幾組：

```bash
PHISH_WU_API_KEY=你的金鑰 python3 import.py --url https://admin.example.com --only 01,08,09
```

匯入後請務必在管理介面以 **Send Test Email** 寄一封給自己，確認變數替換、附件與落地頁都如預期。

## 每個情境的破綻（給檢討會用）

演練真正的價值在事後檢討。每個情境刻意留下的識別點記錄在 `manifest.json` 的 `tells` 欄位，可直接拿來做教材。例如情境 08：

> - 最經典的手法：用「帳號已被入侵」的恐懼讓人跳過查證
> - 弔詭之處在於，宣稱密碼可能外洩卻要你把密碼輸入到信中的連結
> - 真正的資安警示會要你自行前往入口網站，而非點擊郵件連結

列出全部：

```bash
python3 -c "import json;d=json.load(open('manifest.json',encoding='utf-8'));[print(i['id'],i['slug'],*('  - '+t for t in i['tells']),sep=chr(10)) for i in d['items']]"
```

## 修改

`emails/`、`pages/`、`attachments/` 底下都是可直接編輯的 HTML，改完重新匯入即可。`manifest.json` 只存放名稱、主旨與旗標，不含內容。

可用的樣板變數：`{{.FirstName}}`、`{{.LastName}}`、`{{.Email}}`、`{{.Position}}`、`{{.URL}}`、`{{.Tracker}}`、`{{.TrackingURL}}`、`{{.AttachmentTrackingURL}}`、`{{.From}}`、`{{.RId}}`、`{{.BaseURL}}`。

附件中的變數只會在 `.txt`、`.html`、`.ics` 與 Office XML 格式（`.docx`、`.xlsx`、`.pptx` 等）中被替換，其他格式原樣送出。

落地頁的表單 `action` 保持為空字串，由釣魚伺服器接收提交；欄位名稱 `username` 與 `password` 是 gophish 的慣例，改名會影響結果頁的顯示。

### 重新導向

所有落地頁的 `redirect_url` 預設為空。建議指向你自己的教育訓練頁面——提交後立刻看到「這是一次演練」的說明，是整個流程中教學效果最強的一刻。

## 使用前提

這些素材只能用於**你有權限測試的對象**。企業內部演練通常需要人資或法務的事前核可，部分產業另有通報義務。素材庫本身不包含任何惡意程式碼，但寄送釣魚郵件給未經授權的對象在多數司法管轄區都是違法行為。
